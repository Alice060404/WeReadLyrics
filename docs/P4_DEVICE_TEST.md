# P4 一加 11 日志层同步验证

## 目的与边界

验证 0.5.0 能把 P3 的只读 Hook 事件转换为标准会话、播放、暂停、跳转、章节和停止状态。当前仍没有悬浮窗；日志不得包含正文、书名、bookId、原始 utteranceId 或章节号。

诊断配置使用 1 秒 stop+start 合并窗口和 15 秒暂停清理超时。前者覆盖 P3 观察到的 65 毫秒以内重启组合；后者保留约 9 秒暂停样本后仍能最终清屏。这些数值只用于 P4 验证，不是最终产品精度承诺。

## 操作步骤

1. 经用户许可安装 0.5.0，并由用户完全关闭、重新打开微信读书。
2. 确认十个 Hook 安装成功，且无 `Probe install failed` 或 `Sync flush failed`。
3. 开始朗读约 20 秒，暂停约 5 秒，再继续约 15 秒。
4. 执行一次前跳或后跳，再切换章节，分别等待一句完整语音。
5. 停止朗读并等待至少 16 秒，以触发诊断清理超时。
6. 用户确认实际发声与内置高亮正常；导出时只保留 `Sync event=` 摘要。

## 判定

- `PASS`：标准事件序号单调；当前文本长度、token 和范围随发声项推进；跳转/切章清除旧项；最终状态进入 `IDLE` 且文本长度为 0；宿主无回归。
- `PARTIAL`：主要文本关联正确，但控制组合、章节或超时状态不能稳定归一化。
- `FAIL`：显示预取文本、旧事件回退、正文泄漏、状态不清理或影响宿主行为。
