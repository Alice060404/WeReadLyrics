# P3 一加 11 只读探测

## 目的与边界

验证微信读书 10.2.2 的现有朗读高亮事件是否与实际 AI 语音同步，并用播放器生命周期区分暂停、继续与停止。模块不改变参数、返回值或播放流程；不记录正文、书名、bookId 或原始 utteranceId。日志只含事件类型、单调序号、相对毫秒、文本或标识长度、进程内随机盐短哈希、字符范围和线程名。

安装 0.3.0 APK 和重新启动微信读书前须取得用户许可。发现闪退、卡顿、朗读异常或日志包含正文时立即停止，禁用模块并重新打开微信读书。

## 操作步骤

1. 更新安装 `app/build/outputs/apk/debug/app-debug.apk`，确认 LSPosed 作用域仍只有微信读书。
2. 用户关闭并重新打开微信读书；确认日志显示高亮及播放器共七个 Hook 安装完成，且没有 `Probe install failed`。
3. 清晰报出“开始”，随后启动 AI 朗读并连续播放约 60 秒。
4. 在一句正在发声时报出“暂停”并暂停约 5 秒，再报出“继续”并恢复。
5. 等待自然换句；随后报出“停止”并停止朗读。
6. 导出这段时间的 `WeReadLyrics` 日志。只保留探针字段，不保存其他设备日志或书籍正文。

## 判定

- `PASS`：高亮 start 随当前发声推进，播放器生命周期能区分暂停、继续和停止；暂停期间高亮不推进，继续后恢复，短哈希和范围能区分换句，且无宿主回归。
- `PARTIAL`：能观察文本/进度，但事件提前、滞后、缺少生命周期或不能可靠区分当前播放项。
- `FAIL`：候选方法未调用、只反映预取、正文泄漏或影响微信读书行为。

本轮人工口令只能提供粗粒度时间参照，不宣称毫秒级准确度。
