# P5 一加 11 实时字幕与 IPC 验证

## 目的

验证 0.7.0 只在用户启动实时模式后接受微信读书 10.2.2 的签名调用，并把 P4 当前项显示在悬浮窗。日志只保留状态、序号和长度，不导出正文。

## 操作步骤

1. 经用户许可安装 0.7.0；完全关闭并重新打开微信读书，使新 Hook 代码生效。
2. 打开 WeReadLyrics，确认悬浮权限仍有效，点击“启动实时字幕”。通知应显示实时模式，未朗读时屏幕上没有字幕条。
3. 打开微信读书开始 AI 朗读，观察字幕是否随实际句子更新；切到桌面和浏览器继续观察。
4. 暂停约 5 秒：字幕应保留并变淡，且不推进；继续后恢复正常亮度和更新。
5. 执行前跳、后跳和切章：旧字幕应立即清除，随后显示新播放项。
6. 停止朗读并等待至少 16 秒：字幕应消失，实时模式通知仍保留以等待下一次朗读。
7. 从通知或管理界面停止悬浮字幕，再次朗读：字幕不得自行出现，证明 Hook 不能后台创建服务。

## 证据与判定

保留 `IPC connected`、`IPC accepted`、`Overlay applied` 和错误类型的脱敏日志。额外检查私有 Overlay Service 不能由 shell 外部启动；Bridge 接口由非微信读书 UID 调用时必须拒绝。

- `PASS`：真实字幕关联正确；暂停、跳转、切章、停止和用户关闭均按预期；鉴权及生命周期检查通过；微信读书无可见回归。
- `PARTIAL`：主要字幕正确，但 IPC 重连、系统后台行为或个别状态异常。
- `FAIL`：未授权来源可更新字幕、正文进入日志/磁盘、旧字幕残留，或影响宿主运行。
