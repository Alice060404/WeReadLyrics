# P5 一加 11 模拟悬浮窗验证

## 当前范围

0.6.0 只验证本地模拟字幕，不接收微信读书正文，也不包含跨进程 IPC。悬浮服务由用户在可见的模块界面中启动；服务不导出。

## 操作步骤

1. 经用户许可安装 0.6.0，打开 `WeReadLyrics`。
2. 允许通知；点“授予悬浮窗权限”，在系统页面允许本应用显示在其他应用上层，然后返回。
3. 确认页面显示“悬浮窗权限：已授予”，点“显示模拟字幕”。
4. 确认字幕每 3 秒切换，共包含短句和长句；长句最多显示两行并在末尾省略。
5. 拖动字幕到屏幕不同位置；切换到桌面、浏览器和微信读书，确认仍可见且可拖动。
6. 从通知点“隐藏”，确认字幕消失且前台服务结束；再次显示后确认位置得到保留。
7. 返回管理界面再次显示和隐藏，确认应用无崩溃或无响应。

## 判定

- `PASS`：授权路径正常；字幕可跨应用显示、更新、拖动和隐藏；两行策略生效；通知和服务生命周期正确；没有可见宿主回归。
- `PARTIAL`：基本显示正常，但某个系统界面、拖动边界、通知或生命周期行为异常。
- `FAIL`：无法授权或显示、字幕无法清理、服务崩溃，或影响微信读书。

模拟模式通过后才接入受保护 IPC；构建成功不等同于本项通过。
