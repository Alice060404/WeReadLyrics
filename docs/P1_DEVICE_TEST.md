# P1 一加 11 真机验证

## 目的与影响

验证 LSPosed 能识别 API 102 模块，并将模块加载到微信读书主进程。操作会在一加 11 安装 Debug APK、修改 LSPosed 模块启用/作用域状态，并需要重新启动微信读书进程。执行前须取得用户许可；不重启设备，不清空 App 数据。

## 操作步骤

1. 安装 `app/build/outputs/apk/debug/app-debug.apk`。
2. 在 LSPosed 的“模块”中确认出现 WeReadLyrics，启用模块，并确认作用域只有微信读书 `com.tencent.weread`。
3. 用户关闭并重新打开微信读书，确认阅读和 AI 朗读仍可正常启动。
4. 读取 LSPosed 日志，查找标签 `WeReadLyrics`。预期出现包名、进程名和 `firstPackage`，不应包含书籍原文。
5. 验收主进程名为 `com.tencent.weread`；若出现其他后缀进程，仅记录事实，不把它当作主进程成功证据。

## 故障与回滚

- 模块未出现：检查 APK 是否包含 `META-INF/xposed/` 三个文件及 API 102 属性。
- 没有日志：检查模块开关、静态作用域和微信读书是否在启用后重新启动。
- 微信读书异常：立即停止测试，在 LSPosed 中禁用模块并重新启动微信读书；保留脱敏崩溃摘要，不上传账号信息或正文。
- 卸载模块前再次取得用户许可；绝不清空微信读书数据。
